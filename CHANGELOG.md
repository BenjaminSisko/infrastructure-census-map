# Changelog

## 0.3.0 - 2026-10-06

Finished pilot operator workflow with doctor/demo/collect/finish CLI, user-owned census-output defaults, automatic playbook rendering and WinSCP transfer archives with explicit file allowlists. Added matching-system offline staging/install helpers, public-source release/privacy gate, qualification/developer/WinSCP guides and MIT license. Enforced Linux query limits while reading, protected existing seals, retained missing expected assets in products, aligned browser/manual validation and corrected visible manual-versus-measured attribution. Production platform qualification remains a separate canary gate.

## 0.2.0 — 2026-10-06

Added an offline visual workbench for host selection, evidence inspection, editable notes/manual context, manual asset and relationship management, pan/zoom/drag, and JSON context import/export. Browser drafts are scoped to an evidence/model workspace; collected records remain unchanged. Workbench exports round-trip through the existing manual-context renderer and agent workflow.

## 0.1.1 — 2026-10-05

Added manual YAML/JSON context for uncollected infrastructure assets, existing host metadata, custom attributes, hosting/storage/backup/management/dependency relationships, source hash and review attribution. Combined and manual-only rendering is supported. Collected identity/address conflicts are retained, hosting cycles are rejected, and no network port is inferred for placement. Updated Ansible render entry point, HTML details/filter/legend, CSV and reports.

## 0.1.0 — 2026-10-05

Initial portable prototype: Linux/Windows/network Ansible collection, per-section statuses, expected-scope manifest and SHA-256 bundle verification, generic inventory, fictional fixtures, common evidence schema, agent instructions, offline-controller guide, platform guides, and deterministic SVG/HTML/CSV/JSON/Markdown products.
